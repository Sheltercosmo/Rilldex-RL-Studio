Import and interpretation

Import a frozen development experiment with python -m rilldex activity-components import DIRECTORY --name "Comparison name". Source trajectories must already be present. Authored fixtures are skipped.

Imports validate saved source spans, cutoffs, tool contracts, options and argmax choices. Provider identity and reuse metadata are declarations in the imported records. These checks do not certify semantic correctness, prompt quality or independent reference labels.

Each record keeps its own request and field ownership. Missing fields display “Not requested.” Changed option definitions are excluded from comparable-choice counts.
