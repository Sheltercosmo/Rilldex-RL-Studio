# Archived UI experiments

These files preserve the previous source workbench and map/rollout visualizations for development reference. They are not served as product pages.

The supported workflow is Overview → Monitors / Investigations → Rollouts → Behavior map or Source record, with Connections for capture. The source reader uses existing saved records and performs no annotation/model jobs. Historical backend data and APIs are retained.

Old /legacy/semantic-map and /legacy/rollouts bookmarks forward to current views. Checkpoint studies and the graph-query prototype are removed from shared navigation; their existing direct routes remain available for historical research records.
