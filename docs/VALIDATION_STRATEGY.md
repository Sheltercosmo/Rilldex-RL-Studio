## What the long simulation bypasses

- Real source variability: coherent but wrong reasoning, unstructured results,
  missing identifiers, multilingual/long outputs and variable context budgets.
- Candidate proposal, finite-choice selection and repair: no candidate omissions,
  wrong alternatives, inconsistent links or semantic errors enter the scenario.
- Provider behavior: no live rate limits, truncations, changing model versions,
  proxy failures or measured token/cost distributions.
- Native runtime behavior: no genuine scheduling, partial generation across
  policy updates, trainer consumption, resource contention or capture overhead.
- Independent outcomes: pattern labels and expected values are authored together.
  Their agreement establishes deterministic invariants, not empirical accuracy.

The monitor service consumes saved observations. An opt-in semantic worker now
follows completed sources with a persistent allowance and publishes base
observations under a stable identity. Its replay/fault tests are separate from
the long simulation: they do not prove fresh inference accuracy or production
scheduling. Automatic extraction and saved-metric refresh must not both be
called "real time" without this distinction.

## Required validation sequence

1. **Unmodified real-trace replay.** Mix pinned framework/environment formats,
   successes/failures and long/short traces. Preserve native identities, actual
   clocks and missing fields. Deliver through real collectors under independent
   reorder, duplication, outage and burst schedules. Label imposed schedules as
   test conditions, not observed production timing. Check lost/duplicated joins,
   memory growth, unresolved coverage and exact evidence retrieval.
2. **Fresh semantic extraction on a frozen task-disjoint reference set.** Run the
   real candidate proposer and Jev transport end to end. Keep reference labels,
   rewards and future suffixes outside applicable requests. Score segmentation,
   activity, target identity and relations separately, then measure error in
   downstream recovery/branch/verification statistics. References need independent
   review; model agreement and self-authored examples are not that reference.
   Cache unchanged requests, log actual usage, stop at an explicit call/token
   budget and retain failed attempts. Cached replay tests correctness of reuse,
   not current provider behavior or fresh accuracy.
3. **Native collection with a real agent/environment.** Execute a small agent
   against actual tools, record its policy/inference requests and environment
   effects, then run observation and inspection. Exercise external failures and
   observation lag independently. This can be much cheaper than RL training and
   tests genuinely produced behavior, but does not prove trainer integration.
4. **Native training and deployment.** Run capture-on/off controls on supported
   Linux/container stacks; reconcile emitted samples with actual loss/optimizer
   inputs. Include a distinct asynchronous framework, cancelled/partial/retried
   work, policy changes, checkpoint resume and multiple producers. Measure latency,
   backlog and resource overhead under realistic rate/size distributions.
5. **Researcher decision tests.** Freeze several known and competing mechanisms:
   actual regression, delayed reporting, changed task mix, verifier failure,
   policy lag and reward/outcome disagreement. Determine whether a researcher can
   find the evidence and distinguish them, including "insufficient evidence."
   A chart rendering without error is not a successful diagnostic workflow.

## Architectural implications to validate

- Explicit observation jobs with source/protocol identities, budget, pending,
  running, failed and published states; restart-safe execution and backpressure.
  Reuse the staged extraction/cache implementation, rather than calling models
  from the dashboard request path.
- Separate source completeness, annotation completeness and metric availability.
  An unavailable semantic stage cannot silently produce a zero behavior rate.
- Prefix-scoped online observations versus full-trajectory retrospective ones;
  no reused full-trace decision is evidence of prefix-only performance.
- Bind scheduler attempts, source revisions, model policy segments and actual
  training uses explicitly. Unjoined or conflicting evidence stays unresolved.
- Publish changes to a protocol with versioned metrics and controlled evaluation;
  do not silently reinterpret an older training curve.

These are acceptance requirements, not claims that the remaining gates have
passed. Synthetic tests remain useful for precise regression coverage; they
cannot substitute for these gates, regardless of rollout count.
