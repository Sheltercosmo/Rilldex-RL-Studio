## Known implementation limits

- The local server is designed for an individual researcher, without multi-user authentication or deployment packaging.
- Command-purpose fallbacks are conservative heuristics, not validated semantic labels. Compound shell commands usually stay unresolved.

- Environment configuration is a selected-field projection, not a complete environment specification. It supports inspection and comparison guards but is not yet included in Jev's action packets.

- Objective candidates are extractive English-language plan blocks, not a validated semantic ontology. Paraphrases are not merged; source user-role amendments are recorded without inferring supersession.
- Checkpoint intervals cover paired task variation, not inspector error or within-task rollout uncertainty. No real checkpoint-indexed trajectory dataset has yet been integrated; the comparison workflow is verified on clearly labeled synthetic fixtures.
- Historical threshold receipts are not current selection rules. The successful live API pass establishes the integration path, not annotation accuracy or generalization; current decisions use argmax without a confidence filter.
