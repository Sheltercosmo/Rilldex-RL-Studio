# Workspace navigation

Select the workspace and training run once in the sidebar.

| Layer | Use |
| --- | --- |
| Training | Overview, signals and run comparison, behavior, execution, training data. |
| Investigate | Open a rollout, inspect its map and source, or return to a saved investigation. |
| Monitoring | Configure measures, alerts and reward checks. |
| Workspace | Manage runs, files, capture and integrations. Folded outside setup. |

Page tabs change the view of the current evidence. Selecting a point, interval, branch or revision opens its details and relevant actions. Compare within that view; revisions stay inside rollout flow. Advanced settings and evidence chains remain folded.

Behavior measures show results first. Expand **Measurement inputs** for capture, workload and metric setup.

Search (`Ctrl K`) opens nested tools directly, including **After an error** and **Revision benefit & harm**. Pin an exact view to retain its filters and evidence revision. Back returns to the originating comparison.
